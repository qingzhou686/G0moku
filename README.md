# 五子棋（Gomoku）

纯前端五子棋网站，无需安装任何依赖，双击 `index.html` 即可离线游玩。

## 玩法

- **人机对战**：可选执黑（先手）或执白（后手），三档难度
  - 简单：经常漏看威胁，适合新手
  - 普通：贪心策略，会封堵各类棋形
  - 困难：额外识别「双杀」并避免走进对手的两步杀，实测对普通难度胜多负少
- **双人对战**：同一台设备上轮流落子
- **悔棋**：人机模式会一次退回两手，直到重新轮到你落子
- **落子记录**：侧栏实时显示每一手，最新一手高亮
- 其余：坐标开关、落子音效、胜负计数、五连高亮与结算卡片

快捷键：`U` 悔棋 · `R` 重新开始 · `空格` 音效开关 · `Esc` 关闭结算卡片

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 样式与响应式布局 |
| `game.js` | 纯逻辑：胜负判定、棋形评分、AI 决策（无 DOM 依赖） |
| `app.js` | Canvas 棋盘渲染、交互、对局流程 |
| `test-core.js` | 核心逻辑测试，`node test-core.js` 运行 |
| `五子棋.html` | 单文件版，样式脚本全内联，双击即用、可直接发给别人 |
| `build-single.js` | 由上面四个文件生成单文件版，`node build-single.js` |
| `serve.js` + `启动本地服务器.bat` | 局域网共享，同一 WiFi 下别人也能打开 |
| `部署说明.md` | 发布到公网的几种方式（GitHub Pages / Netlify / Vercel…） |
| `preview.png` | 页面预览图 |

## 测试

```bash
node test-core.js
```

覆盖：四个方向的五连判定、被堵住的不算赢、AI 取胜与封堵行为、
候选点合法性、多局自我对弈的正确终止（并用独立暴力扫描交叉验证胜负）、
难度分级有效性、单步耗时上限。

## 实现说明

- 棋盘用 Canvas 绘制，按设备像素比渲染，网格与棋子在任意尺寸下都保持清晰；木纹背景只在尺寸变化时重建一次。
- AI 为启发式评分：统计每个候选点在四个方向上的连子数与封堵情况，
  按「成五 / 活四 / 冲四 / 活三 …」查表计分，并同时计算该点对对手的价值（用于封堵）。
- 困难难度在此基础上增加双杀识别与两步杀防守，实测单步决策在 2ms 左右。
